# P9 — Satellite Anomaly Detection (IASTAM 6.0)

## Folder layout (matches ~/Documents/p9/)
- `P9_Satellite_Anomaly_Detection_Complete.ipynb` — the full notebook (already executed once:
  open it and every figure/metric is visible without rerunning anything).
- `data/satellite_telemetry.csv` — synthetic dataset generated by Pipeline A (regenerated
  deterministically, seed=42, each time you run the notebook).
- `external/opssat-ad/data/dataset.csv` — the real OPS-SAT-AD dataset
  (https://github.com/kplabs-pl/OPS-SAT-AD), bundled so the notebook runs out of the box.
- `outputs/` — the 10 PNG figures + `all_results.csv`, pre-rendered for the pitch video / paper.

## How to run in VS Code
1. Python + Jupyter extensions installed.
2. Open this folder (`p9/`) in VS Code so the notebook's relative paths resolve correctly.
3. `pip install numpy pandas scikit-learn matplotlib`
4. Open the `.ipynb`, pick a Python kernel, "Run All".

If `external/opssat-ad/data/dataset.csv` is ever missing, the "fetch dataset" cell clones
https://github.com/kplabs-pl/OPS-SAT-AD automatically and copies it into place.
